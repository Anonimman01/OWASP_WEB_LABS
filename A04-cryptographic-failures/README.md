# A04 — Cryptographic Failures (криптографические сбои)

**Статус:** 🕓 запланировано

## О чём лаба
Данные передаются или хранятся без должной защиты: слабое хеширование паролей, устаревшие алгоритмы, ключи в коде, отсутствие HTTPS.

## Чему научитесь
- Отличать безопасное хранение паролей от небезопасного
- Понимать, почему MD5 и SHA-1 не подходят для паролей
- Не хранить секреты в исходном коде

## Цель лабы
Найти слабое место в хранении или передаче данных и исправить его в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
