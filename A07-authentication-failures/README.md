# A07 — Authentication Failures (сбои аутентификации)

**Статус:** 🕓 запланировано

## О чём лаба
Слабая проверка личности: простые пароли, нет защиты от перебора, небезопасные сессии и токены, нет MFA.

## Чему научитесь
- Понимать, как работают сессии и токены
- Защищаться от перебора паролей
- Безопасно хранить и обновлять сессии

## Цель лабы
Получить доступ к чужому аккаунту из-за слабой аутентификации, затем исправить код в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
