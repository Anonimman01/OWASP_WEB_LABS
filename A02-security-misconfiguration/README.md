# A02 — Security Misconfiguration (небезопасная конфигурация)

**Статус:** 🕓 запланировано

## О чём лаба
Ошибки в настройках: пароли по умолчанию, включённый debug-режим, подробные ошибки, лишние открытые сервисы, отсутствие защитных заголовков.

## Чему научитесь
- Находить небезопасные настройки в приложении и окружении
- Настраивать защитные HTTP-заголовки
- Отключать отладку и лишние функции в продакшене

## Цель лабы
Найти утечку информации из-за неверной конфигурации, затем исправить настройки в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
