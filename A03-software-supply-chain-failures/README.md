# A03 — Software Supply Chain Failures (сбои в цепочке поставок ПО)

**Статус:** 🕓 запланировано

## О чём лаба
Уязвимые или скомпрометированные зависимости, подмена пакетов, небезопасная сборка и доставка кода.

## Чему научитесь
- Проверять зависимости на известные уязвимости
- Понимать риски транзитивных зависимостей
- Фиксировать версии и составлять SBOM

## Цель лабы
Найти уязвимую зависимость в проекте и заменить её на безопасную версию в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
