# A01 — Broken Access Control (нарушение контроля доступа)

**Статус:** 🕓 запланировано

## О чём лаба
Пользователь получает доступ к данным или функциям, которые ему не положены: чужие профили, админ-панель, чужие заказы.

## Чему научитесь
- Находить IDOR (подмена идентификатора в URL или запросе)
- Понимать разницу между аутентификацией и авторизацией
- Проверять права на стороне сервера при каждом запросе

## Цель лабы
Получить доступ к данным другого пользователя, затем исправить код в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
