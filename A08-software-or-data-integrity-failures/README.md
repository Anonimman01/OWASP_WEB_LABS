# A08 — Software or Data Integrity Failures (нарушения целостности ПО и данных)

**Статус:** 🕓 запланировано

## О чём лаба
Код и данные принимаются без проверки подлинности: обновления без подписи, небезопасная десериализация, скрипты с недоверенных источников.

## Чему научитесь
- Понимать риски небезопасной десериализации
- Проверять целостность и подпись обновлений и файлов
- Подключать внешние скрипты безопасно (SRI)

## Цель лабы
Показать, как непроверенные данные влияют на поведение приложения, и исправить это в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
