# A06 — Insecure Design (небезопасная архитектура)

**Статус:** 🕓 запланировано

## О чём лаба
Ошибка заложена в самом дизайне: нет лимита попыток, можно обойти шаг оплаты, логика позволяет злоупотреблять функцией.

## Чему научитесь
- Видеть уязвимости бизнес-логики
- Основам моделирования угроз
- Закладывать безопасность на этапе проектирования

## Цель лабы
Найти изъян в логике приложения и предложить исправление в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
