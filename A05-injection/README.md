# A05 — Injection (инъекции)

**Статус:** 🕓 запланировано

## О чём лаба
Недоверенные данные попадают в запрос или команду и меняют их смысл: SQL-инъекции, XSS, внедрение команд ОС.

## Чему научитесь
- Понимать, как данные превращаются в код
- Использовать параметризованные запросы
- Экранировать вывод и валидировать ввод

## Цель лабы
Обойти форму входа или получить лишние данные на уязвимом приложении, затем исправить код в `fixed/`.

## Структура
- `vulnerable/` — уязвимая версия
- `fixed/` — исправленная версия
- `docker-compose.yml` — запуск
